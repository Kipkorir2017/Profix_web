**ProFix mechanical web**
A modern, responsive, and production-ready mechanical engineering company website built using React, Vite, and Tailwind CSS.

This platform is designed for industrial and mechanical engineering businesses that provide:

*Welding & fabrication*
Mechanical repairs
Lathe machine operations
Spare parts supply
Industrial maintenance
Machine servicing

The website is structured as a scalable multi-page application with a professional industrial UI/UX suitable for real-world deployment.

**Tech Stack**
Frontend
React
Vite
Tailwind CSS
React Router DOM
React Icons
Future Backend
Node.js
